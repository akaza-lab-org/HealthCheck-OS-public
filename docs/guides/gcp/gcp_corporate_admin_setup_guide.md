# 法人管理者向け：GCP Vertex AI 利用開始セットアップガイド

このガイドは、法人の IT 管理者が、院内ツール（summarymaker 等）のために Google Cloud Platform (GCP) の Vertex AI を利用可能にするための手順を説明します。

---

## 概要
院内ツールが Google の最新 AI（Gemini）を利用するためには、法人の GCP プロジェクト内に「サービスアカウント」という AI 専用の窓口を作成し、その「鍵（JSONファイル）」をツールに設定する必要があります。

---

## 手順 1: GCP プロジェクトの作成

1. [Google Cloud コンソール](https://console.cloud.google.com/)にログインします。
2. 画面上部のプロジェクト選択メニューから **[新しいプロジェクト]** をクリックします。
3. **プロジェクト名** を入力します（例: `hcos-ai-tools`）。
4. **請求先アカウント** を法人の支払い情報（クレジットカード等）に紐付けます。
5. **[作成]** をクリックします。

---

## 手順 2: Vertex AI API の有効化

AI 機能を利用するための「スイッチ」をオンにします。

1. 作成したプロジェクトが選択されていることを確認します。
2. 左上のナビゲーションメニューから **[API とサービス] > [ライブラリ]** を選択します。
3. 検索窓に `Vertex AI API` と入力し、検索結果から選択します。
4. **[有効にする]** ボタンをクリックします。
   - ※「課金を有効にする必要があります」と出た場合は、画面の指示に従い請求先を紐付けてください。

---

## 手順 3: サービスアカウントの作成と鍵の発行

ツールが AI を使うための「合鍵」を作成します。

1. ナビゲーションメニューから **[IAM と管理] > [サービス アカウント]** を選択します。
2. 上部の **[サービス アカウントを作成]** をクリックします。
3. **サービスアカウント名** を入力します（例: `ai-tool-operator`）。
4. **[作成して続行]** をクリックします。
5. **ロール（権限）の選択** で、以下を検索して追加します：
   - `Vertex AI ユーザー` (Vertex AI User)
6. **[続行]** > **[完了]** をクリックします。
7. 作成されたサービスアカウントのメールアドレスをクリックし、**[キー]** タブを選択します。
8. **[鍵を追加] > [新しい鍵を作成]** をクリックします。
9. **JSON** が選択されていることを確認し、**[作成]** をクリックします。
10. パソコンに `.json` ファイルがダウンロードされます。

---

## 手順 4: 鍵（JSONファイル）の受け渡し

**⚠️ 重要：このファイルは銀行の暗証番号と同じくらい重要です。チャットやメールでそのまま送らないでください。**

開発担当者（Human CTO）へは、以下のいずれかの方法で共有してください：
- 法人指定のセキュアなストレージ（Google Drive / Box 等）へのアップロード
- パスワード付き ZIP ＋ 別経路でのパスワード共有
- 直接対面での USB 手渡し

---

## 開発担当者への連絡事項
セットアップ完了後、以下の情報を開発担当者へ伝えてください：
- **GCP プロジェクト ID**
- **JSON キーファイル（安全な方法で共有）**
- **利用予定のリージョン**（通常は `us-central1` または `asia-northeast1`）

---

## 院内ポータブルアプリ向けキー配置（B案）

Issue #38 の Human CTO 決定に基づき、院内配布で使う JSON キーは次の標準パスで管理します。

```text
%USERPROFILE%\.config\gcp\<appname>_key.json
```

例:

```text
C:\Users\<ユーザー名>\.config\gcp\summarymaker_key.json
```

### PC 側の配置手順

1. エクスプローラーを開き、アドレスバーに `%USERPROFILE%\.config\gcp` を入力して Enter。
2. フォルダがない場合は新規作成する（`.config` と `gcp`）。
3. GCP からダウンロードした鍵ファイル（`.json`）をコピーする。
4. アプリ名が分かる名前に変更する（例: `summarymaker_key.json`）。

注意:
- ZIP 配布対象フォルダ内には置かない。
- メール、Slack、GitHub Issue/PR に添付しない。

---

## `run.bat` / `start.bat` での認証変数設定

アプリ起動時に `GOOGLE_APPLICATION_CREDENTIALS` を設定し、Python 起動前に有効化します。

```batch
set GOOGLE_APPLICATION_CREDENTIALS=%USERPROFILE%\.config\gcp\summarymaker_key.json
python app.py
```

`start.bat` の場合も同様に、Python 実行行の前へ追記してください。

確認ポイント:
- パスに誤字がないこと
- 対象アプリのキー名と一致していること
- 端末固有の運用ファイル（`config.ini` など）を上書きしないこと
